# Contributing

Thank you for helping make this roadmap better. It is meant for everyone who wants to learn and grow in AI hardware, so every improvement helps someone.

## Ways to contribute

- **Fix something:** typos, broken links, outdated tools or wrong facts.
- **Add a resource:** a course, book, paper, tool, talk or reference design that genuinely helped you.
- **Improve a stage:** clearer topics, better milestones, or a missing topic.
- **Add a project brief:** a hands-on project with clear goals and a "done when" checklist.
- **Share your work:** if you completed a milestone or project, a link to your write-up or repo can help others.

## What makes a good resource

Before adding a link, please check that it is:

1. **Useful for this audience:** hardware engineers learning AI hardware, ML-driven verification or hardware-aware ML.
2. **High quality:** you have used it yourself, or it is widely recognised.
3. **Accessible:** free or open source is preferred. Paid resources are fine if they are clearly the best option; mark them with `(paid)`.
4. **Maintained:** for tools and code, the project should be reasonably active or still a standard reference.
5. **Not a duplicate:** search the repo first.

## Formatting

- Put the resource in the stage and track where a learner would need it.
- Use this format for links:

  ```markdown
  - [Name](https://link) - One short sentence on what it is and why it is worth the time.
  ```

- Milestones are checklist items (`- [ ]`) that start with a verb and describe something concrete you can show or measure.
- Keep the tone friendly and plain. Explain acronyms the first time they appear in a section.

## Pull request process

1. Fork the repository and create a branch for your change.
2. Keep each pull request focused on one topic so it is easy to review.
3. In the pull request description, say what you changed and why.
4. Be patient and kind in review. Everyone here is learning.

## Ideas and questions

Not sure whether something fits? Open an issue to discuss it first. Suggestions for new stages, tracks or project ideas are welcome there too.
